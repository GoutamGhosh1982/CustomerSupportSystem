Customer Support Ticketing System

Software & Infrastructure Requirements Documentation

Overview

This is a full-stack microservices application with a React frontend and .NET 10.0 backend services. The system can run via Docker Compose or local development mode.

Deployment Modes

Choose one of the following deployment options:

  • Docker Compose (Recommended) - Single command deployment
  • Local Development - Manual setup for each service

1. System Requirements (All Modes)

Hardware

CPU: 2+ cores (4+ cores recommended)
RAM: 4GB minimum (8GB recommended)
Disk: 10GB free space (for Docker images & databases)
Network: Stable internet connection for Docker image downloads

Operating System

  • Windows 10+ (with Docker Desktop)
  • macOS 10.14+ (with Docker Desktop)
  • Linux (Ubuntu 18.04+, CentOS, Debian, etc.)

2. Docker Compose Mode Requirements

7. Environment Variables Summary

Critical Variables (Auto-set in Docker)

  • ASPNETCORE_ENVIRONMENT=Development (or Production)
  • ConnectionStrings__*Db - Database connection strings
  • Jwt__Secret - JWT signing key
  • RabbitMQ__Host, RabbitMQ__Port - Message broker
  • Smtp__* - Email configuration
All defaults provided in docker-compose.yml for quick start

Troubleshooting Checklist

  • ✓ Verify Docker/Docker Compose installation: docker --version && docker-compose --version
  • ✓ Verify .NET SDK: dotnet --version
  • ✓ Verify Node.js: node --version && npm --version
  • ✓ Check port availability: netstat -tuln | grep LISTEN
  • ✓ Increase Docker memory to 4GB+ in Docker Desktop settings
  • ✓ Clear Docker volumes if database issues: docker-compose down -v
  • ✓ Check RabbitMQ health: http://localhost:15672 (guest/guest)
